How it works

One proposed tool call in, one JSON verdict out. The cascade decides who answers.

1. Agent proposesrole, policy, session facts, conversation, one tool call
→
2. Local adapterGemma 4 E4B + LoRA, free, reports its confidence
→
3. Confident?yes: answer locally. no: ask Gemini with your key
→
4. Verdictallow | block, category, reason

Playground

Edit the call and policy. The instant check is the keyword baseline running in your browser (a floor, not a real guard). For the real prompt, paste your own Gemini API key: the request goes from your browser straight to Google and the key is never stored unless you tick the box.

The cached local-model verdict for the preset examples was measured on the 8-bit adapter. Hosted calls bill your own Google account.

Policy test suite

Save the current call as a test with the verdict you expect, run the whole suite against the keyword baseline (or Gemini), and export the report. Stored only in your browser.

The cascade

Idea: the local adapter's confidence is a cheap signal. Confident calls stay free, uncertain ones go to Gemini. The sliders replay Project A's real agent traffic (held-out half, thresholds were fit on the other half).

Results

Project A's real agent traffic, 95% family-clustered bootstrap intervals. Higher block rate and lower false positives are better.

Read this plainly: the free local model is clearly weaker than hosted Gemini on real traffic. It is a cheap first pass, not a gate for destructive, financial or data-export actions. Full tables and caveats: RESULTS.md.

Use it in your agent (MCP)

A stdio MCP server exposes check_tool_call, explain_categories and cascade_stats. Backends: keyword (default, no model), local, gemini (your key), cascade.

git clone https://github.com/brej-29/toolcall-guard
cd toolcall-guard
uv run --no-project --with "mcp<2" python -m tcg.mcp_server
{
  "mcpServers": {
    "toolcall-guard": {
      "command": "uv",
      "args": ["run", "--no-project", "--with", "mcp<2", "python", "-m", "tcg.mcp_server"],
      "cwd": "/path/to/toolcall-guard",
      "env": { "GUARD_BACKEND": "keyword" }
    }
  }
}
Config shape follows the common MCP client format. The server starts and lists its tools over the SDK; end-to-end use inside each client is untested here.

FAQ

Is this a security boundary?

No. It is a pre-execution check. Use it with least-privilege tools and human review for destructive actions.

Why bother if Gemini is better?

Cost, privacy and offline use. The cascade measures how much of Gemini's quality you keep while sending fewer calls to it.

Where does my API key go?

Only to Google's API from your browser, and only if you click Check with Gemini. This site has no server.
