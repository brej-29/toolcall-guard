Plug it into your agent.

A stdio MCP server with check_tool_call, explain_categories and cascade_stats. Backends: keyword (default), local, gemini (your key), cascade.

git clone https://github.com/brej-29/toolcall-guard
cd toolcall-guard
uv run --no-project --with "mcp<2" python -m tcg.mcp_server
{
  "mcpServers": {
    "toolcall-guard": {
      "command": "uv",
      "args": ["run", "--no-project", "--with", "mcp<2", "python", "-m", "tcg.mcp_server"],
      "cwd": "/path/to/toolcall-guard",
      "env": { "GUARD_BACKEND": "keyword" }
    }
  }
}

The server starts and lists its tools. Use inside each client is untested here.

Questions.

Is this a security boundary?

No. It is a pre-execution check. Pair it with least-privilege tools and human review for destructive actions.

Why bother if Gemini is better?

Cost, privacy and offline use. The cascade measures how much of Gemini's quality you keep while sending fewer calls to it.

Where does my API key go?

Only to Google's API, from your browser, and only when you press Check with Gemini. This site has no server.
