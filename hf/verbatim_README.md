# Toolcall Guard data, verbatim archive (private)

The verbatim records the model BrejBala/gemma-toolcall-guard was trained and evaluated on. They contain invented
contact details written by Gemini (Gmail addresses, phone numbers). Not for publication: the public dataset is the
sanitized release at BrejBala/toolcall-guard-data, identical except for those details.
